# Perícia Lab · Carômetro

App de som direto do reality *Perícia Lab – o Jogo*: escalação de transmissores e cápsulas por episódio, input list para imprimir, devolução de equipamento e simulador de mesa (Scorpio + CL-12).

- **App:** `index.html` (uma página, publicada pelo GitHub Pages)
- **Ligação com a planilha:** `apps-script/Codigo.gs`
- **Instalação:** [docs/como-instalar.md](docs/como-instalar.md)
- **Formato do settings do Scorpio:** [docs/scorpio-settings.md](docs/scorpio-settings.md)

## O que não entra aqui

O repositório é público. Fotos e nomes dos participantes, a planilha, os arquivos de settings do Scorpio (têm nome, telefone e e-mail) e o link de convite do app ficam só no Drive.
